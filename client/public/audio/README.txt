Put your looping track here as:  ambient.mp3
(path is set in src/context/MusicContext.jsx)

LICENSING — read this before picking a track.
You need a licence that covers commercial use on a website. Do not use a
commercial song (Spotify/YouTube rip) — for a business community site that is
a real legal risk, not a theoretical one.

Safe sources:
  - Pixabay Music        free, commercial use allowed
  - Uppbeat              free tier with attribution
  - Free Music Archive   check the per-track licence
  - Epidemic Sound       paid subscription

PICKING A TRACK
  - Loop it cleanly, or the seam will be audible every play.
  - Ambient / lo-fi / soft downtempo. Nothing with vocals or a strong beat —
    people read this site.
  - 1-3 minutes is plenty. It loops.

FILE SIZE
  Export mono, 96-128kbps. A 2-minute loop should land around 1-2MB.
  The file is only downloaded if a visitor turns music on, so it costs
  nothing for everyone who doesn't.
